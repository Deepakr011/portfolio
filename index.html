RFID-Based Telephone System

700+ telephone units manufactured. Designed to replace coin-box telephones in school hostels, the system lets students below Class 12 make calls with an RFID card where mobile phones are prohibited. The product uses an STM32F103C8T6 microcontroller, an MFRC522 reader for RFID call access, and a GSM module for calls. Firmware was developed in STM32CubeIDE and flashed using STM32CubeProgrammer. It tracks the daily call allowance on the card. To recharge the card, the Flutter recharge app communicates with a separate recharge machine over Bluetooth Low Energy (BLE). The machine writes the updated balance to the RFID card.

STM32F103C8T6 · STM32CubeIDE · STM32CubeProgrammer · RFID · GSM · BLE · Flutter · Embedded C++
